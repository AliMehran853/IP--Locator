# 🌐 IP Information & Location Mapper
A simple and powerful Python tool to fetch detailed information about any IP address, including its geolocation and an auto-generated interactive map.  
This project is useful for **Cyber Security**, **OSINT**, **Network Analysis**, and educational purposes.

---

## 🚀 Features
- Fetch full IP information using the `ipinfo.io` API  
- Display location, ISP/organization, region, and more  
- Auto-generate an interactive map using **Folium**  
- Opens the map directly in the browser  
- Colored CLI output for better readability  
- Error handling for invalid IP or network failures
